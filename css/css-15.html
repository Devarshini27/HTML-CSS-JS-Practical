CSS Overflow

Managing content that exceeds an element's size.

Aim

To demonstrate overflow, overflow-x and overflow-y properties.

Working Output

overflow: hidden

Extra content is hidden when it exceeds the box.

overflow: auto

This box automatically provides scrolling when required. This is additional content.

overflow-x: auto
Horizontal scrolling content → CSS Overflow Demonstration

Source Code

overflow: auto;

overflow-x: auto;

Concepts

overflow, overflow-x, overflow-y, scrolling
