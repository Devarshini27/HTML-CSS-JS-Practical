Positioning content using float and clear.

Aim

Working Output

Floated Box

This paragraph flows around the floated element. The float property allows an element to move to the left or right while surrounding content wraps around it. This is useful for understanding traditional CSS layouts.

This section uses clear: both;, so it appears below the floated element.

Source Code

clear: both;
