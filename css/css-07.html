CSS PROGRAM 07

CSS Gradients

Create a webpage using Linear and Radial CSS gradients.

Aim

To demonstrate linear and radial gradients using CSS.

Working Output

Linear Gradient
Radial Gradient

Source Code

.linear {
    background:
        linear-gradient(
            135deg,
            blue,
            purple,
            pink
        );
}

.radial {
    background:
        radial-gradient(
            circle,
            green,
            blue,
            navy
        );
}
