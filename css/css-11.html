Width & Height

Create a webpage using different width, height, min-width, max-width, min-height, and max-height properties.

Aim

To demonstrate different CSS width and height properties and their minimum and maximum limits.

Source Code

    width: 60%;

    height: 150px;

    max-width: 700px;

    min-height: 120px;

    max-height: 200px;

}
