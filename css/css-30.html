CSS Filters

Applying visual effects using CSS filter properties.

Aim

To demonstrate CSS filters including blur, grayscale, brightness, contrast and opacity.

Working Output

Blur

Grayscale

Brightness

Contrast

Opacity

Source Code

filter: blur(4px);

filter: grayscale(100%);

filter: brightness(1.6);

filter: contrast(180%);

filter: opacity(40%);

Concepts

blur, grayscale, brightness, contrast, opacity, filter
