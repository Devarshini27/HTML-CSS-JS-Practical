CSS PROGRAM 03

Combinator Selectors

Create a webpage using Descendant, Child, Adjacent Sibling, and General Sibling selectors.

Aim

To demonstrate the use of Descendant, Child, Adjacent Sibling, and General Sibling CSS selectors.

Working Output

Child selector: direct child

Descendant selector: element inside parent

First element
Adjacent sibling selector
Sibling element
General sibling selector
Another general sibling

Source Code

/* Descendant Selector */

.parent .descendant {
    color: yellow;
}


/* Child Selector */

.parent > .child {
    background: blue;
}


/* Adjacent Sibling Selector */

.first + .adjacent {
    color: green;
}


/* General Sibling Selector */

.sibling ~ .general {
    color: pink;
}

Concepts Used
