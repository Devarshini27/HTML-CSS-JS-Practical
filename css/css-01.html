CSS PROGRAM 01

Types of CSS

Create a webpage using Inline, Internal, and External CSS.

Aim

To create a webpage demonstrating the use of Inline CSS, Internal CSS, and External CSS.

Description

CSS can be applied to HTML elements in three different ways: Inline CSS, Internal CSS, and External CSS. This experiment demonstrates all three methods.

Working Output

1. Inline CSS

This text uses Inline CSS.


2. Internal CSS

This text uses Internal CSS.


3. External CSS

This text demonstrates External CSS.

Source Code

<!-- Inline CSS -->

<p style="color: orange;">
    This text uses Inline CSS.
</p>


<!-- Internal CSS -->

<style>

.internal-text {
    color: blue;
    font-size: 22px;
}

</style>

<p class="internal-text">
    This text uses Internal CSS.
</p>


<!-- External CSS -->

<link rel="stylesheet" href="style.css">

<p class="external-text">
    This text uses External CSS.
</p>
