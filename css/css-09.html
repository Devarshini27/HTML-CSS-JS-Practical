CSS Text Properties

Create a webpage using CSS text alignment, decoration, transformation, indentation, spacing, and line-height.

Aim

To demonstrate different CSS properties used for formatting text.

Source Code

.align {
    text-align: center;
}

.decorate {
    text-decoration: underline;
}

.transform {
    text-transform: uppercase;
}

.indent {
    text-indent: 40px;
}

.spacing {
    letter-spacing: 4px;
    word-spacing: 10px;
}

.height {
    line-height: 2;
}
