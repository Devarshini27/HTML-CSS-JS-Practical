CSS PROGRAM 02

CSS Selectors

Create a webpage using Universal, Element, Class, ID, Attribute, and Grouping selectors.

Aim

To create a webpage demonstrating different types of CSS selectors.

Description

CSS selectors are used to select HTML elements and apply styles to them. This experiment demonstrates Universal, Element, Class, ID, Attribute, and Grouping selectors.

Working Output

1. Universal Selector

The * selector applies styles to all elements.

2. Element Selector

This heading is styled using an element selector.

3. Class Selector

This paragraph uses a class selector.

4. ID Selector

This paragraph uses an ID selector.

5. Attribute Selector

6. Grouping Selector

Multiple selectors can share the same CSS rule.

Source Code

/* Universal Selector */

* {
    margin: 0;
    padding: 0;
}


/* Element Selector */

h4 {
    color: green;
}


/* Class Selector */

.class-example {
    color: orange;
}


/* ID Selector */

#id-example {
    color: pink;
}


/* Attribute Selector */

input[type="text"] {
    border: 2px solid blue;
}

input[type="email"] {
    border: 2px solid green;
}


/* Grouping Selector */

.group-title,
.group-description {
    color: purple;
}

Concepts Used
