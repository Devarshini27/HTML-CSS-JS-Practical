CSS Box Model

Create a webpage using the CSS box model with content, padding, border, and margin.

Aim

To demonstrate the CSS box model consisting of content, padding, border, and margin.

Working Output

Content Area

Padding → 25px
Border → 12px
Margin → 50px

Source Code

.box {
    margin: 50px;

    border: 12px solid orange;

    padding: 25px;

    background: blue;
}

.content {
    background: navy;
}
