HTML PROGRAM 05 / 15

Student Registration Form

Aim

To create a student registration form using HTML form elements.

Working Output

Male Female

Source Code

<form>

    <label>Full Name:</label>
    <input type="text" name="name">

    <label>Email:</label>
    <input type="email" name="email">

    <label>Phone:</label>
    <input type="tel" name="phone">

    <label>Date of Birth:</label>
    <input type="date" name="dob">

    <label>Department:</label>

    <select name="department">
        <option>CSE</option>
        <option>ECE</option>
        <option>EEE</option>
    </select>

    <label>Gender:</label>

    <input type="radio"
           name="gender"
           value="male">
    Male

    <input type="radio"
           name="gender"
           value="female">
    Female

    <label>Address:</label>

    <textarea rows="4"
              cols="30">
    </textarea>

    <input type="submit"
           value="Register">

    <input type="reset"
           value="Reset">

</form>

Concepts Used

• form

• input elements

• radio buttons

• select and option

• textarea

• submit and reset buttons
