Responsive Webpage

Aim

To create a responsive webpage using CSS media queries.

Working Output

HTML
CSS
JavaScript

Source Code

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

.box {
    background: orange;
    padding: 30px;
    text-align: center;
}

@media (max-width: 850px) {

    .grid {
        grid-template-columns: repeat(2, 1fr);
    }

}

@media (max-width: 550px) {

    .grid {
        grid-template-columns: 1fr;
    }

}
