HTML5 Input Types

Aim

To create a webpage using HTML5 input types such as email, date, number and password.

Working Output



Source Code

<form>

    <label>Email:</label>
    <input type="email">

    <label>Date:</label>
    <input type="date">

    <label>Number:</label>
    <input type="number">

    <label>Password:</label>
    <input type="password">

    <input type="submit"
           value="Submit">

</form>

Concepts Used

• email input

• date input

• number input

• password input

• submit button
