HTML PROGRAM 02 / 15

HTML Lists

Aim

To create an HTML page containing ordered, unordered, and description lists.

Working Output

Ordered List

  1. HTML
  2. CSS
  3. JavaScript
  4. Python

Unordered List

  • Python
  • C Programming
  • Git
  • Web Development

Description List

HTML
HTML is used to create the structure of webpages.
CSS
CSS is used to style and design webpages.
JavaScript
JavaScript is used to add interactivity to webpages.

Source Code

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>HTML Lists</title>
</head>

<body>

    <h2>Ordered List</h2>

    <ol>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
        <li>Python</li>
    </ol>

    <h2>Unordered List</h2>

    <ul>
        <li>Python</li>
        <li>C Programming</li>
        <li>Git</li>
        <li>Web Development</li>
    </ul>

    <h2>Description List</h2>

    <dl>

        <dt>HTML</dt>
        <dd>
            HTML is used to create the structure of webpages.
        </dd>

        <dt>CSS</dt>
        <dd>
            CSS is used to style and design webpages.
        </dd>

        <dt>JavaScript</dt>
        <dd>
            JavaScript is used to add interactivity to webpages.
        </dd>

    </dl>

</body>

</html>

Concepts Used

• Ordered list — ol

• Unordered list — ul

• List item — li

• Description list — dl

• Description term — dt

• Description details — dd
