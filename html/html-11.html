Internal & External CSS

Aim

To create a webpage with internal and external CSS styling.

Working Output

This heading uses Internal CSS

This paragraph uses External CSS.

Source Code

<link rel="stylesheet"
      href="html-11-style.css">

<style>

.internal {
    color: orange;
    font-size: 30px;
}

</style>

<h1 class="internal">
    This uses Internal CSS
</h1>

<p class="external">
    This paragraph uses External CSS.
</p>

Concepts Used

• Internal CSS

• External CSS

• class selectors

• link element
