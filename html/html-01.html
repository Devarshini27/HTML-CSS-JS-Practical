HTML PROGRAM 01 / 15

Basic HTML Webpage

Aim

To create a basic HTML webpage using headings, paragraphs, and line breaks.

Working Output

Welcome to My Webpage

HTML Basics

This is a paragraph created using HTML.

My Introduction

My name is Devarshini Lakshmi Akshaya.
I am a B.Tech Computer Science Engineering student.
I am learning HTML, CSS and JavaScript.

My Interests

Web Development
Programming
Creating Websites

Source Code

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Basic HTML Webpage</title>
</head>

<body>

    <h1>Welcome to My Webpage</h1>

    <h2>HTML Basics</h2>

    <p>
        This is a paragraph created using HTML.
    </p>

    <h3>My Introduction</h3>

    <p>
        My name is Devarshini Lakshmi Akshaya.<br>
        I am a B.Tech Computer Science Engineering student.<br>
        I am learning HTML, CSS and JavaScript.
    </p>

    <h2>My Interests</h2>

    <p>
        Web Development<br>
        Programming<br>
        Creating Websites
    </p>

</body>

</html>

Concepts Used

• HTML document structure

• Headings using h1, h2 and h3

• Paragraphs using p

• Line breaks using br
