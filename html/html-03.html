HTML PROGRAM 03 / 15

HTML Tables

Aim

To create a webpage using tables with rows, columns, borders, and merged cells.

Working Output

Student Details
Name Course Year
Devarshini B.Tech CSE 2
Akshaya CSE 2
Sai University

Source Code

<table border="1">

    <tr>
        <th colspan="3">Student Details</th>
    </tr>

    <tr>
        <th>Name</th>
        <th>Course</th>
        <th>Year</th>
    </tr>

    <tr>
        <td>Devarshini</td>
        <td>B.Tech CSE</td>
        <td>2</td>
    </tr>

    <tr>
        <td rowspan="2">Akshaya</td>
        <td>CSE</td>
        <td>2</td>
    </tr>

    <tr>
        <td colspan="2">Sai University</td>
    </tr>

</table>

Concepts Used

• table

• tr — table row

• th — table heading

• td — table data

• colspan — merge columns

• rowspan — merge rows
